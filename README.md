Now it uses actual image files from images/gallery/ for better quality, faster loading, and a richer visual experience.  ### How It Works  #### 1. Image Data Array All images are defined in a JavaScript array galleryData:  javascript {   src:    'images/gallery/lucknow-election-2019-1.jpg',   title:  '2019 लखनऊ लोकसभा चुनाव',   desc:   '2019 लखनऊ लोकसभा चुनाव में सभी 1826 बूथों पर...',   category: 'चुनावी कार्य' }   The expand() helper function generates multiple numbered entries automatically:  javascript expand('lucknow-election-2019', 3, 'Title', 'Description', 'चुनावी कार्य') // Creates 3 items: lucknow-election-2019-1, -2, -3   #### 2. Categories (Filter Tabs) | Category | Hindi Label | Image Groups | |----------|-------------|--------------| | चुनावी कार्य | Election Work | lucknow-election-2019, ch, radha, raju, 2019-lok, lucknow-17 | | संघ व ABVP | RSS & ABVP | 1986, 1992, 2000, ram, akhil, mumbai | | शीर्ष नेतृत्व | Top Leadership | rj, jeevan, bjp-dun, atal, pkd, pr | | सामाजिक एवं विधिक | Social & Legal | seal-2025, high-court-2025, cp, kal, yuva, mw, up, dutta-tre |  Clicking a filter tab re-renders the grid to show only matching images.  #### 3. Masonry Layout The gallery uses CSS Columns (not CSS Grid) for true masonry:  css .gallery-masonry {   column-count: 4;        /* 4 columns on desktop */   column-gap: 1.25rem; } .gallery-item {   break-inside: avoid;    /* Prevents image splitting across columns */   margin-bottom: 1.25rem; }   This ensures images of different heights flow naturally without awkward gaps.  #### 4. Hover Effects Each gallery card has layered effects on hover: - Border: Glows orange (rgba(234,88,12,0.6)) - Shadow: Orange drop shadow appears - Lift: Card moves up 4px and scales 1.01x - Image: Scales to 1.06x with smooth transition - Overlay: Gradient darkens from 60% to 100% opacity - Zoom icon: Fades in at top-right - Content: Slides up from bottom  #### 5. Lightbox Clicking any image opens a full-screen lightbox: - Image: Scales in with bounce easing - Navigation: Left/right arrows + keyboard (← →) - Counter: Shows 3 / 90 style position - Info: Title (amber) + description below image - Close: X button or Escape key or click outside  ---  ## 🌌 Three.js Hero Background  The hero section has an animated 3D background:  ### Scene Elements | Element | Description | |---------|-------------| | Particles | 450 orange glowing dots floating in space | | Icosahedron Core | Golden metallic sphere at center | | 3 Torus Rings | Orbiting rings in orange/gold, rotating at different speeds | | Point Lights | Orange and gold lights creating depth |  ### Animation Loop javascript t += 0.005; particles.rotation.y = t * 0.15;   // Slow drift group.rotation.y = t * 0.4;           // Core spins group.position.y = Math.sin(t * 0.6) * 0.25;  // Floats up/down camera.position.x = Math.sin(t * 0.1) * 0.3;   // Gentle pan   The canvas is pointer-events: none so it doesn't block clicks on the hero content.  ---  ## 📱 Responsive Breakpoints  | Breakpoint | Gallery Columns | Navigation | |------------|-----------------|------------| | < 640px | 1 column | Hamburger menu | | 640px+ | 2 columns | Hamburger menu | | 1024px+ | 3 columns | Full desktop nav | | 1280px+ | 4 columns | Full desktop nav |  ---  ## ⚡ Performance Features  1.
